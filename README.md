# Puzzle do Ritmo 0.8

14 estudos de solfejo: 12 estudos originais progressivos e os dois exercícios anteriores. Seis etapas conduzem da clave de Sol à clave de Fá, às mãos alternadas e às duas mãos simultâneas com ritmos e acordes.

No modo 07, abra Ajustes para escolher etapa, estudo, andamento e mãos que deseja ouvir. Desative Avançar automaticamente entre compassos para estudar um compasso por vez. O próximo compasso aparece como preparação; no último tempo, recebe destaque.

Inclui os modos anteriores de puzzle e treino rítmico, interface para computador, tablet e celular, instalação PWA e cache offline após o primeiro acesso.

Este modo reproduz e marca a partitura; não escuta nem avalia o piano físico.

Testes: node tests/curriculum.cjs; node tests/solfege.cjs; node tests/regression.cjs.

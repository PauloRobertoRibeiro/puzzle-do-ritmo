# Puzzle do Ritmo

Aprenda leitura rítmica ouvindo, reconhecendo e montando figuras musicais.

## Versão 0.3

- 12 melodias originais, 48 compassos, em três etapas progressivas.
- Conhecer os sons, montar livremente, reconhecer ritmos, montar puzzles e montar músicas.
- Compassos 2/4, 3/4 e 4/4; semínimas, mínimas, colcheias, semicolcheias, figuras pontuadas e pausas.
- Reprodução com destaque visual, andamento ajustável e metrônomo opcional.
- Aplicativo web instalável para computador, Android e iPhone/iPad.
- Progresso no navegador, exportação/importação JSON, sem cadastro ou API paga no aplicativo.

## GitHub Pages

Envie os arquivos desta pasta para a raiz do repositório. Em Settings → Pages, selecione Deploy from a branch → main → /(root) e salve. Aguarde o processo em Actions e abra o endereço informado pelo GitHub.

Todos os caminhos são relativos: o app pode ser hospedado em uma subpasta do GitHub Pages. Não mova apenas o index.html: ele precisa de todos os arquivos JavaScript, CSS, ícones e manifesto.

## Instalação

Abra o endereço HTTPS no Chrome/Android ou Safari/iOS. Use o botão Instalar aplicativo para receber as instruções. O navegador oferece a instalação quando suportada. A primeira abertura requer internet; o cache permite reutilizar os recursos já baixados.

## Dados

Dados não sincronizam automaticamente entre aparelhos ou endereços. Use Guardar cópia e Restaurar cópia ao trocar de navegador ou hospedagem. Nenhum áudio é gravado ou enviado: os sons musicais são sintetizados no aparelho.

As alturas do modo Monte a música são guiadas. O aluno reconstrói o ritmo, e ainda não escolhe manualmente as alturas nem importa gravações.

## Verificação desta versão

Verificados os tempos de nove peças, 5.400 desafios gerados e os dados de áudio/partitura dos 48 compassos. A qualidade física do áudio, o toque e a instalação devem ser conferidos nos aparelhos em uso.
